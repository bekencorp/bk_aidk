Armino AIDK SDK Code download
--------------------------------------------------------------------

We can download Armino AIDK SDK from gitlab::

    mkdir -p ~/armino
    cd ~/armino
    git clone --recurse-submodules http://gitlab.bekencorp.com/armino/bk_ai/bk_aidk.git -b branch_name

!Note:

    Please replace branch_name with the actual branch or tag.


Build Compilation Environment:
--------------------------------------------------------------------

Armino supports firmware burning on Windows/Linux platforms.

For burning methods, please refer to the guidance documents within the burning tool.

For Windows platform, as an example, Armino currently supports UART burning.

 `Burning Process Documentation <https://docs.bekencorp.com/arminodoc/bk_idk/bk7258/en/v2.0.1/get-started/index.html>`_ please refer to the IDK Documentation `IDK <https://docs.bekencorp.com/arminodoc/bk_idk/bk7258/en/v2.0.1/index.html>`_
